8 modules · 16 selected practice problems · researched 2026-10-26

World Finals preparation is the regional and championship core plus selective specialist depth and much stronger integration. W01-W06 are an elective menu: do not make every item a prerequisite for attempting finals sets. W07 and W08 are practical training skills; protocol knowledge can also be needed much earlier.

Priority: first repair weaknesses exposed by full sets. Add an advanced structure only when the team can explain when it is useful and maintain a tested implementation. A verified basic drill under a specialist module validates a prerequisite, not the whole module.

Extra laboratories: for half-plane intersection, compare the fast algorithm with repeated convex clipping on small bounded instances; test empty and unbounded intersections separately. For suffix trees, use the distinct-substring and repeated-substring tasks from C06 as alternative implementations. For Markov hitting times, construct small chains with known expectations and unreachable absorbing states. These are explicitly self-authored validation exercises, not invented online-judge problems.

Specialist problems: see Past papers for NEERC 2010 J (half-plane intersection), IOI 2016 Aliens (penalty optimization; not an ICPC problem), and World Finals 2025 C/G/I. The other finals selections show how fundamentals still matter.

Exit evidence: improvement across unseen full sets, reliable code under contest conditions, and clear team decisions about which hard tasks to pursue. There is no fixed syllabus or problem quota that guarantees a finals result.

How to use each module

Work in prerequisite order. Attempt starter, then core, then stretch. These labels are relative to the module, not official platform difficulties. W01 · Dynamic sequences and forests

Prerequisites: C01,C03.

Learn: Implicit treap split/merge and lazy reversal; link-cut trees; preferred paths; dynamic path queries; randomized balancing.

Mastery check: Stress-test every operation against a vector or small explicit forest, including cut/relink and reversed paths.

Watch for: Implementing a dynamic tree without a verified invariant; stale lazy tags during rotations.

Study: Treap; KACTL reference and testing guidance.

Understand the idea

Implicit treaps store a sequence by subtree sizes rather than explicit keys. Split and merge support insertion, deletion, reversal, and interval aggregates in expected logarithmic time under randomized priorities. Push lazy tags before descending and pull aggregates after structural changes. Link-cut trees maintain changing forests through preferred paths and splay operations, supporting link, cut, reroot, and path queries. Dynamic subtree aggregates require additional bookkeeping beyond a basic path implementation.

Worked example / reasoning

To reverse [l,r), split the sequence at l and again at r-l, toggle the middle tree's reversal tag, and merge the pieces. For a dynamic forest, reject a link that would create a cycle. A cut operation must confirm the requested vertices form the intended edge after exposing the path.

Learning sequence

  1. Stress-test treap operations against a vector with retained random seeds.
  2. Learn splay invariants and lazy propagation before using a link-cut template.
  3. Compare every dynamic-forest operation with BFS and explicit adjacency sets on tiny forests.

W02 · Advanced optimization and algebraic DP

Prerequisites: C04,C08.

Learn: Lagrangian/Alien trick and tie handling; discrete convexity; slope trick; generating-function manipulations; formal power series; linear recurrence techniques.

Mastery check: Explain which optimum a penalty search returns and why the target count is recoverable.

Watch for: Assuming any cardinality-constrained DP supports Alien trick; confusing coefficient truncation with evaluation.

Study: Operations on polynomials and series; KACTL reference and testing guidance.

Understand the idea

Algebraic DP optimization requires proving structure in the value function. Alien optimization adds a penalty per chosen group and searches for a penalty producing the required count; convexity and tie handling determine whether the original value can be recovered. Slope trick maintains breakpoints of a convex piecewise-linear function through DP transitions. Formal power series work with coefficients only up to a required degree and impose invertibility conditions on operations such as reciprocal, logarithm, and exponential.

Worked example / reasoning

Penalizing every partition by lambda often makes the optimal number of parts decrease as lambda increases. Store both penalized cost and count with an explicit tie policy; a jump over the desired count needs a structural argument, not arbitrary interpolation. For a series inverse, the constant coefficient must be invertible in the coefficient field.

Learning sequence

  1. Derive the unoptimized recurrence and prove the convexity needed by the selected technique.
  2. Plot a small piecewise-linear DP function and track its breakpoints manually.
  3. Compare truncated polynomial operations and recurrence acceleration with direct computation.

Watch, read, and go deeper

W03 · Specialist geometry

Prerequisites: C10.

Learn: Half-plane intersection; Minkowski sums; polygon clipping; minimum enclosing circle; 3D vector/plane geometry; planar duality; Voronoi/Delaunay awareness.

Mastery check: Specify boundedness and degeneracy behavior; compare small cases against slower geometric checks.

Watch for: Treating all geometry as epsilon comparisons; using a 2D formula unchanged in 3D.

Study: Half-plane intersection - S&I Algorithm in O(N log N); Minkowski sum of convex polygons; Minimum Enclosing Circle.

Understand the idea

Specialist geometry combines sophisticated structures with reliable elementary predicates. Half-plane intersection tracks the boundary of a convex feasible region and must handle parallel constraints and unbounded cases. Minkowski sums merge edge directions of convex polygons. Minimum enclosing circle uses randomized incremental constraints and needs correct one-, two-, and three-point boundary solvers. In three dimensions, distinguish point, line, and plane degeneracies. Voronoi and Delaunay structures are useful to recognize even when a simpler reduction is preferable.

Worked example / reasoning

The Minkowski sum A+B consists of all a+b with a in A and b in B. For convex polygons listed consistently, their edge direction sequences can be merged in linear time after normalization. To test whether two convex polygons intersect, reasoning about A+(-B) reduces the question to whether the origin belongs to that sum.

Learning sequence

  1. Implement clipping or half-plane intersection with a documented empty/unbounded representation.
  2. Test minimum enclosing circle against exhaustive small boundary candidates.
  3. Practice 3D dot/cross products on parallel, coplanar, and nearly degenerate inputs.

Watch, read, and go deeper

W04 · Specialist graphs and optimization

Prerequisites: C07,R11.

Learn: General matching/blossom; global min-cut; dominators; directed MST; flow with demands; linear programming and duality; recognize when a smaller special case suffices.

Mastery check: Translate the combinatorial constraints into an exact optimization model and justify the reduction.

Watch for: Using bipartite matching on a non-bipartite graph; inferring ordinary max flow from a story about pipes.

Study: Minimum cut - Stoer-Wagner algorithm; KACTL reference and testing guidance.

Understand the idea

Specialist graph problems often differ from familiar ones by one decisive assumption. General matching needs blossom contraction because odd cycles break bipartite augmenting-path logic. Directed MST seeks a rooted arborescence and cannot use undirected cut reasoning unchanged. Dominators capture vertices unavoidable on paths from a fixed root. Global minimum cut differs from a chosen source-sink cut. Linear programming models continuous variables and gives dual certificates, but integrality requires an additional theorem or formulation property.

Worked example / reasoning

In a triangle, the bipartite alternating-layer viewpoint encounters an odd cycle; blossom contraction preserves the ability to search for augmenting paths through it. For optimization modeling, a fractional assignment or flow may be integral because of the structure of its constraint matrix, while an arbitrary linear relaxation of a discrete problem need not be.

Learning sequence

  1. Identify which assumption prevents a standard bipartite or undirected algorithm from applying.
  2. Validate a specialist implementation on exhaustive tiny graphs.
  3. Write both primal and dual constraints for a small optimization model and interpret a certificate.

Watch, read, and go deeper

Matching and LP foundations; general blossoms, dominators, and directed MST are separate specialist algorithms.

W05 · Advanced strings

Prerequisites: C06.

Learn: Lyndon factorization; minimal rotation; suffix trees as an optional alternative; palindromic trees; runs and periodicity; advanced string DP.

Mastery check: Explain when suffix array/automaton already suffices and justify the extra machinery before implementing it.

Watch for: Learning multiple complex structures without a use case; incorrect sentinel/alphabet assumptions.

Study: Lyndon factorization; Suffix Tree.

Understand the idea

Advanced string methods expose periodicity and repeated structure without enumerating every substring. Lyndon factorization decomposes a string into a canonical ordered sequence of primitive factors and supports minimal-rotation reasoning. A palindromic tree has one node per distinct palindrome and suffix links between palindromic suffixes; it complements Manacher's position-centered radii. Runs describe maximal periodic regions, while suffix trees offer an alternative index with substantial implementation complexity. Choose a structure according to the actual query rather than its generality.

Worked example / reasoning

For ababa, the distinct nonempty palindromes are a, b, aba, bab, and ababa. A palindromic tree represents these five objects, whereas Manacher stores a radius for each center. Appending one character can create at most one new distinct palindrome, which explains the linear node bound behind the palindromic tree.

Learning sequence

  1. Implement minimal rotation and compare it with sorting all rotations for small strings.
  2. Build an eertree and verify distinct palindromes and occurrence propagation.
  3. Study periodicity proofs before attempting run enumeration or advanced string DP.

Watch, read, and go deeper

W06 · Specialist mathematics and games

Prerequisites: C08,C09,R19.

Learn: Miller-Rabin/Pollard rho; discrete logarithm; Burnside; interpolation; determinants and Matrix-Tree theorem; impartial games combined with structural graph arguments.

Mastery check: State algebraic preconditions, overflow bounds, and randomized failure assumptions; prove structural game reductions.

Watch for: Treating a probabilistic primality result as deterministic without appropriate bases and bounds.

Study: Primality tests; Integer factorization; Discrete Log; Burnside's lemma / Pólya enumeration theorem; Kirchhoff Theorem.

Understand the idea

Specialist mathematics demands attention to theorem conditions and arithmetic scale. Miller-Rabin bases determine the range of a deterministic primality test; Pollard rho is randomized factorization and requires safe modular multiplication. Discrete logarithms have coprimality and subgroup issues. Burnside averages fixed objects over a group action. Interpolation depends on the coefficient field, and Matrix-Tree turns a graph-counting problem into a determinant of a Laplacian minor. Game reductions still require legal-move and termination proofs.

Worked example / reasoning

To count colorings of a cycle up to rotation, sum the colorings fixed by each rotation and divide by the number of rotations under Burnside's lemma. Modular division requires that group size be invertible, or a different arithmetic strategy. For a connected undirected graph, deleting one row and matching column from its Laplacian gives a determinant equal to the number of spanning trees.

Learning sequence

  1. Verify primality and factorization routines against a sieve on a large small-number range.
  2. Enumerate tiny group actions and compare orbit counts with Burnside.
  3. Check Matrix-Tree determinants against exhaustive spanning-tree subsets on small graphs.

Watch, read, and go deeper

Arithmetic and polynomial-transform prerequisites; use the specialist references for factorization, group actions, determinants, and discrete logarithms.

W07 · Interactive and output-sensitive work

Prerequisites: P16,R20.

Learn: Interactive protocols; flushing; query budgets; local mock judges; adaptive adversaries; constructive output validation; numerical tolerances.

Mastery check: Write a protocol simulator and prove both query budget and correctness; validate constructed answers independently.

Watch for: Continuing after an error sentinel; forgetting to flush; a correct idea that exceeds output or query limits.

Study: KACTL reference and testing guidance.

Understand the idea

Interactive tasks are useful specialist training, although they should not be assumed to appear in a particular ICPC event. Treat the judge interface as a protocol: legal queries, response interpretation, termination signals, flush behavior, and a strict query budget. A mock judge makes these properties testable. Output-sensitive algorithms express cost in terms of both input and produced output. For constructive and numerical tasks, validate the output by the specification rather than comparing with one sample answer.

Worked example / reasoning

In a hidden-number comparison task, maintain the set of numbers consistent with every response and choose queries that reduce the worst-case remaining set. If the judge returns an error or termination marker, stop according to the protocol. For a construction with many valid answers, check structure, range, uniqueness, and objective value rather than expecting a particular sequence.

Learning sequence

  1. Build a local judge that tests every small hidden instance and counts queries.
  2. Exercise early termination, invalid responses, and boundary query budgets.
  3. Write an independent checker for a construction and a scale-aware numerical comparator.

Watch, read, and go deeper

Adaptive search and adversary reasoning; implement protocol handling and a local checker independently.

W08 · World Finals integration

Prerequisites: C12,W07; W01-W06 are electives.

Learn: Read all problems; locate approachable tasks; combine fundamentals with structural insight; choose specialist depth by team coverage; rehearse the full environment.

Mastery check: Work through several unseen World Finals sets, retain a clear postmortem, and stress-test the reference library.

Watch for: Assuming every finals problem needs an advanced named algorithm or that ratings predict a team's score.

Study: KACTL reference and testing guidance.

Understand the idea

World Finals integration means selecting useful work across the entire set and maintaining correctness over a long session. Specialist topics are electives for team coverage; strong fundamentals remain essential for approachable problems and for the components of hard reductions. Rehearse the actual environment, reference access, compiler behavior, and communication rules for the target event. Analyze official solution material only after an honest attempt, and distinguish multiple valid methods from a single prescribed editorial path.

Worked example / reasoning

After reading a set, maintain a short list of solution hypotheses, unresolved proof obligations, likely implementation cost, and a named owner. If a specialist route stalls, recheck the constraints for a smaller special case or a simpler structural observation. Afterward, compare the team's decisions with what was realistically solvable at each point, not only with hindsight.

Learning sequence

  1. Run a complete unseen final-style set and preserve a decision timeline.
  2. Upsolve an approachable miss and one problem requiring a new structural idea.
  3. Rotate explanation duties so every team member can audit shared reference code and major reductions.
