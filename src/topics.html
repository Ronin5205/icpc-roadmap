STAGE 01

Preliminaries

Foundations, implementation, and core problem solving.

  1. P01

    Language, complexity, and arithmetic

    Prerequisites: None

    C++17/20 syntax and STL; input until EOF and multiple cases; integer division; 64-bit arithmetic; O(1), logarithmic, linear, n log n, quadratic and exponential bounds; memory estimates.

  2. P02

    Simulation and careful implementation

    Prerequisites: P01

    Translate rules into explicit state transitions; arrays, grids, indices, simultaneous versus sequential updates; counting and running extrema.

  3. P03

    Elementary strings and parsing

    Prerequisites: P02

    Character classification; case conversion; lexicographic comparison; runs; palindrome checks; subsequences versus substrings; token versus whole-line input.

  4. P04

    Sorting, comparators, and order

    Prerequisites: P02

    Sort numbers and pairs; stable ordering; tie handling; distinct values; coordinate compression as an introduction.

  5. P05

    Frequency counting, sets, and maps

    Prerequisites: P03,P04

    Frequency arrays; map/set/multiset; hash maps; duplicate handling; algebraically transform a pair condition into equal keys.

  6. P06

    Prefix sums and difference arrays

    Prerequisites: P02

    Half-open and inclusive ranges; prefix sums; prefix counts; difference updates; 2D prefix sums; prefix XOR.

  7. P07

    Two pointers and sliding windows

    Prerequisites: P04,P06

    Opposite-end scans; positive-sum windows; distinct-element windows; maintaining counts; amortized linear movement.

  8. P08

    Binary search and answer search

    Prerequisites: P04,P06

    lower_bound/upper_bound; first true/last false; prefix search; monotone feasibility; integer and real domains.

  9. P09

    Enumeration, recursion, and bits

    Prerequisites: P01

    Subsets and permutations; recursion and backtracking; pruning with proof; bit tests, popcount, XOR; exhaustive small-instance solvers.

  10. P10

    Greedy proofs, invariants, and construction

    Prerequisites: P04,P09

    Exchange arguments; staying ahead; parity and conservation; feasibility then construction; extremal choices; counterexample hunting.

  11. P11

    Elementary number theory and counting

    Prerequisites: P01,P09

    GCD/LCM; sieve; divisors and prime factorization; modular arithmetic; fast exponentiation; basic permutations/combinations; pigeonhole arguments.

  12. P12

    Basic dynamic programming

    Prerequisites: P06,P09

    State, transition, base case, order and answer; memoization versus iteration; min/max/count DP; coin change; reconstruction.

  13. P13

    Graph and tree foundations

    Prerequisites: P02,P09

    Adjacency lists; BFS/DFS; grid flood fill; components; unweighted shortest paths; parent/depth; bipartiteness; forest versus tree.

  14. P14

    Geometry and numerical basics

    Prerequisites: P01,P08

    Coordinates and vectors; squared distance; dot/cross products; orientation; area; rounding and absolute/relative error; exact integer predicates.

  15. P15

    Elementary games and probability

    Prerequisites: P09,P11,P12

    Winning/losing states; small-state minimax; parity strategies; equally likely outcomes; binomial counting; expected value and indicators.

  16. P16

    Preliminary contest integration

    Prerequisites: P01-P15

    Read and triage a whole set; estimate implementation cost; construct counterexamples; debug with brute force; split work and maintain a submission log.

STAGE 02

Regionals

The main algorithmic toolkit, with continued fundamentals practice.

  1. R01

    Ordered structures and monotonic structures

    Prerequisites: P04,P05,P07

    Heaps; balanced ordered sets; event sorting; nearest smaller/greater; monotonic stacks/deques; interval scheduling and sweep events.

  2. R02

    DP breadth: knapsack, sequences, grids, intervals

    Prerequisites: P12,P13

    0/1 and unbounded knapsack; value-indexed DP; LIS O(n log n); LCS/edit distance; interval DP; DAG DP; weighted interval scheduling.

  3. R03

    Small exponential methods

    Prerequisites: P09,P12

    Meet in the middle; bitmask DP; subset transitions; Hamiltonian path/TSP; assignment counting; distinguish O(2^n), O(n2^n), and O(3^n).

  4. R04

    Tree DP and rerooting

    Prerequisites: P13,R02

    Subtree sizes; diameter; independent sets and matching; merge child states; rerooting via outside contributions and prefix/suffix merges.

  5. R05

    Binary lifting, Euler flattening, and LCA

    Prerequisites: P13,R06

    Ancestor jumps; entry/exit times; subtree intervals; lowest common ancestor; distances; path differences; functional graph jumps.

  6. R06

    Fenwick, segment trees, and sparse tables

    Prerequisites: P06,P08

    Fenwick point-update/range-sum; segment tree associative merges; static idempotent RMQ; coordinate compression; order statistics.

  7. R07

    Lazy propagation and richer range queries

    Prerequisites: R06

    Range add/assign; composition order; aggregate length; bracket merges; search inside segment trees.

  8. R08

    DSU and minimum spanning trees

    Prerequisites: P04,P13

    Union by size and path compression; Kruskal/Prim; cycle and cut properties; offline reverse processing; MST edge replacement.

  9. R09

    Shortest paths and state expansion

    Prerequisites: P13,R01

    Dijkstra; 0-1 BFS; Bellman-Ford; Floyd-Warshall; negative-cycle relevance; multilayer graphs; reconstructing paths.

  10. R10

    Directed structure, SCC, and 2-SAT

    Prerequisites: P13,R09

    Topological sorting; DAG DP; SCC condensation; implication graphs; satisfiability and assignment extraction.

  11. R11

    Bridges, articulation points, and BCC

    Prerequisites: P13,R08

    DFS discovery/low values; bridges; articulation roots; edge-biconnected compression; vertex-biconnected blocks and block-cut trees.

  12. R12

    Euler trails and graph construction

    Prerequisites: P10,P13

    Hierholzer; in/out-degree conditions; connectivity of used edges; directed versus undirected trails; de Bruijn construction.

  13. R13

    Bipartite matching and max flow

    Prerequisites: P13,R09

    Augmenting paths; Kuhn and Hopcroft-Karp; residual networks; Dinic; min-cut; edge-disjoint paths; vertex splitting; Konig's theorem.

  14. R14

    Modular combinatorics and recurrences

    Prerequisites: P11,P12

    Factorials/inverses; binomial coefficients; stars and bars; inclusion-exclusion; extended GCD; CRT including noncoprime moduli; matrix exponentiation.

  15. R15

    String matching, hashing, and tries

    Prerequisites: P03,P05

    Prefix function/KMP; Z-function; borders and periods; Rabin-Karp; polynomial hashes and collision risk; ordinary and binary tries.

  16. R16

    Planar geometry and sweep lines

    Prerequisites: P14,R01

    Segment intersection; polygon area and point inclusion; convex hull; polar-angle order; rotating calipers; closest pair; coordinate transforms.

  17. R17

    Offline queries and square-root decomposition

    Prerequisites: P06,R06

    Block decomposition; offline sweeps; Mo's algorithm and add/remove contributions; choosing block sizes; query reordering.

  18. R18

    Numerical search and linear algebra introduction

    Prerequisites: P08,P14,R14

    Unimodality; ternary/golden-section search; numerical bisection; vectors, rank and linear systems; Gaussian elimination with pivoting; exact versus floating fields.

  19. R19

    Regional games and probability

    Prerequisites: P15,R02,R14

    Nim; mex and Sprague-Grundy; disjoint impartial games; probability DP; linearity of expectation.

  20. R20

    Regional contest integration

    Prerequisites: P16,R01-R19

    Model unfamiliar statements; combine two standard tools; test reference code; estimate team opportunity costs; prepare a permitted reference document.

STAGE 03

Championship

Advanced techniques, stronger proofs, and combined models.

  1. C01

    Heavy-light decomposition and small-to-large

    Prerequisites: R04,R05,R07

    Heavy paths; path aggregates and updates; direction-sensitive merges; DSU-on-tree/sack; small-to-large amortization.

  2. C02

    Centroid decomposition and tree counting

    Prerequisites: R04,R05

    Centroid balance; nearest marked vertex; distance histograms; subtract within-child pairs; bitmask parity on paths.

  3. C03

    Persistence, rollback, and parallel binary search

    Prerequisites: R06,R08,R17

    Persistent segment trees; version roots; rollback DSU without path compression; segment tree over time; parallel binary search; Kruskal reconstruction trees.

  4. C04

    DP optimization

    Prerequisites: R02,R06,R18

    Convex hull trick/Li Chao; divide-and-conquer DP; Monge and monotone optima; Knuth optimization; prefix-sum acceleration.

  5. C05

    Digit, profile, and subset-transform DP

    Prerequisites: R03,R14

    Digit DP with tight/started flags; broken-profile tiling; SOS DP; subset convolution awareness; memory compression.

  6. C06

    Automata and suffix structures

    Prerequisites: R15

    Aho-Corasick failure links and output propagation; suffix array/LCP; suffix automaton states and occurrence counts; Manacher odd/even radii.

  7. C07

    Min-cost flow, assignment, and constrained flow

    Prerequisites: R13,R09

    Successive shortest augmenting paths; potentials; negative residual costs; Hungarian assignment; lower-bound circulation; min-cut reductions.

  8. C08

    Advanced number theory and polynomial tools

    Prerequisites: R14

    Mobius inversion; divisor transforms; Euler phi; FFT/NTT; convolution versus correlation; generating functions; polynomial degree and coefficient bounds.

  9. C09

    Probability processes and algebra

    Prerequisites: R18,R19

    Absorbing Markov chains; expected hitting times; self-loops; linear systems over reals and finite fields; XOR basis; transition powers.

  10. C10

    Geometric modeling and transformations

    Prerequisites: R16,R18

    Angular sweeps; line/circle intersections; affine transformations; rotating calipers; convex distance; robust degeneracy handling.

  11. C11

    Amortization and combined structures

    Prerequisites: R07,R09,C01

    Segment-tree graph compression; modulo-update amortization; bitsets; bounded-value tricks; offline/online tradeoffs.

  12. C12

    Championship contest integration

    Prerequisites: R20,C01-C11

    Multi-step reductions; proof-first discussion; deliberate partial progress in training; adversarial testing; responsibility handoffs.

STAGE 04

World Finals

Selective specialist depth alongside complete contest sets.

  1. W01

    Dynamic sequences and forests

    Prerequisites: C01,C03

    Implicit treap split/merge and lazy reversal; link-cut trees; preferred paths; dynamic path queries; randomized balancing.

  2. W02

    Advanced optimization and algebraic DP

    Prerequisites: C04,C08

    Lagrangian/Alien trick and tie handling; discrete convexity; slope trick; generating-function manipulations; formal power series; linear recurrence techniques.

  3. W03

    Specialist geometry

    Prerequisites: C10

    Half-plane intersection; Minkowski sums; polygon clipping; minimum enclosing circle; 3D vector/plane geometry; planar duality; Voronoi/Delaunay awareness.

  4. W04

    Specialist graphs and optimization

    Prerequisites: C07,R11

    General matching/blossom; global min-cut; dominators; directed MST; flow with demands; linear programming and duality; recognize when a smaller special case suffices.

  5. W05

    Advanced strings

    Prerequisites: C06

    Lyndon factorization; minimal rotation; suffix trees as an optional alternative; palindromic trees; runs and periodicity; advanced string DP.

  6. W06

    Specialist mathematics and games

    Prerequisites: C08,C09,R19

    Miller-Rabin/Pollard rho; discrete logarithm; Burnside; interpolation; determinants and Matrix-Tree theorem; impartial games combined with structural graph arguments.

  7. W07

    Interactive and output-sensitive work

    Prerequisites: P16,R20

    Interactive protocols; flushing; query budgets; local mock judges; adaptive adversaries; constructive output validation; numerical tolerances.

  8. W08

    World Finals integration

    Prerequisites: C12,W07; W01-W06 are electives

    Read all problems; locate approachable tasks; combine fundamentals with structural insight; choose specialist depth by team coverage; rehearse the full environment.
